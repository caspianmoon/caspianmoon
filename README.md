## Selected work

### [Memoripy](https://github.com/caspianmoon/memoripy)
A context-aware memory layer for AI applications with short and long-term storage, semantic clustering, graph associations, retrieval, decay, and reinforcement.

### [Replyhold](https://github.com/caspianmoon/replyhold)
A debounce layer for chat-based AI agents. It holds fragmented messages, merges them into one coherent request, and dispatches one response.

### [JSONPaws](https://github.com/caspianmoon/jsonpaws)
A compact Python library for generating structured JSON from language models.
